# キー押しっぱなしツール

Enterキーや任意のキーを「押しっぱなし」または「連打」状態にできる小さなデスクトップアプリです。

## 機能

- **押しっぱなし(ホールド)**: 選んだキーを停止するまで押し続けます
- **連打(リピート)**: 指定した間隔でキーを連打します(間隔は秒で指定、例: 0.05)
- **好きなキーでON/OFF切替**: 他のアプリを操作中でも切替キー1つで開始/停止できます(初期値は F6、あとから変更可能)
- **タスクトレイ常駐**: ウィンドウを閉じても裏で動き続け、切替キーはそのまま使えます。画面を占領しません
- **設定の保存**: 切替キー・対象キー・モード・連打間隔は次回起動時も引き継がれます
- 選べるキー: Enter / Space / Shift / Ctrl / Alt / Tab / 矢印キー / W・A・S・D

## ON/OFF切替キーの変更

1. 画面中央の「ON/OFF切替キー」の右にある **「変更」ボタン** を押す
2. 使いたいキーを押す(その場で登録されます)
3. やめたいときは Esc を押すと取り消されます

設定は自動保存されるので、次回起動時もそのキーが使えます。
(設定ファイルの保存先: ユーザーフォルダの `.key_hold_config.json`)

## タスクトレイについて

ウィンドウの ✕ ボタン(または「トレイにしまう」ボタン)を押すと、画面からは消えますが
**アプリは終了せずタスクトレイ(画面右下の通知領域)に常駐** します。
この状態でも切替キーはそのまま効くので、ウィンドウを出しっぱなしにする必要はありません。

トレイアイコンでできること:

- **クリック** … ON/OFF切替
- **右クリック → 設定ウィンドウを開く** … ウィンドウを再表示
- **右クリック → 終了** … アプリを完全に終了

アイコンの色で状態が分かります(緑=停止中 / 赤=動作中)。
完全に終了したいときは、トレイの「終了」かウィンドウの「アプリを終了」ボタンを使ってください。

## 使い方

### 1. Pythonのインストール(未インストールの場合)

https://www.python.org/downloads/ から最新版をインストールしてください。
インストール時に **「Add Python to PATH」に必ずチェック** を入れてください。

### 2. ライブラリのインストール(初回のみ)

コマンドプロンプトで:

```
pip install pynput pystray pillow
```

### 3. 起動

`key_hold.py` をダブルクリック、またはコマンドプロンプトで:

```
python key_hold.py
```

### 4. 操作

1. キーとモードを選ぶ
2. 「開始」ボタンを押す(または切替キー)
3. 止めたいときは「停止」ボタンか切替キー

## 注意

- macOSの場合は「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でターミナル/Pythonに許可が必要です
- 一部のゲーム(アンチチート搭載)ではソフトウェアによるキー入力が認識されない場合があります
